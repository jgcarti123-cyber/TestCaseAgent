Test_89
Edge Case Needs review

Summary

To verify TCM correctly relays a Remote Lock command from the connected app without the BCM prematurely clearing an active Intrusion Alert, when the driver door is still open in Sleep mode.

Requirement IDs

NIO-F0001_INT_REQ_004 NIO-F0001_INT_REQ_009 NIO-F0001_INT_REQ_011 NIO-F0001_INT_REQ_014

Gherkin

Preconditions: 1. Vehicle locked, all doors closed, Keyfob outside 2. BCM reaches Secured state, then vehicle enters Sleep Test Steps: 1. Open driver door from inside knob, leave it open 2. Confirm Intrusion Alert notification on the app 3. Issue a Remote Lock command from the app while alarm is active 4. Monitor Msg 495 (RemoteVehicleLockCmd) and Msg 738 (BCM status) Expected Result: 1. TCM still accepts and relays the lock command — does not drop it 2. BCM does NOT clear the alarm because of the lock command 3. App shows both the lock acknowledgement AND the alert still active

Rig execution
